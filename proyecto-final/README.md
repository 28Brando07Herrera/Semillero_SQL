## Entregables

1. **Modelo extendido** — las tablas de sus tres módulos, respetando lo que ya existe. No se rompe el núcleo.
2. **Datos coherentes** — que conversen con las fincas, lotes y siembras que ya están cargados.
3. **Tres vistas de reporte** que respondan preguntas reales de negocio.
4. **Índices justificados**, con `EXPLAIN QUERY PLAN` como prueba de que sirven.
5. **`README.md`** con el diagrama del modelo y las decisiones de diseño que tomaron.
