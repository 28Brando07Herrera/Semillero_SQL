# Entregas

Cada uno crea **su propia carpeta** con el formato `apellido-nombre` y pone ahí sus archivos:

```
entregas/
├── perez-juan/
│   ├── Ejercicio3_Perez_Juan.sql
│   └── Ejercicio4_Perez_Juan.sql
└── gomez-ana/
    └── Ejercicio3_Gomez_Ana.sql
```

En `_plantilla/` está el esqueleto del archivo de entrega. Copialo, no lo edites en su lugar.

El paso a paso para entregar está en [CONTRIBUTING.md](../CONTRIBUTING.md).
